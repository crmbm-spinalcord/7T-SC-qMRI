# 7T SC quantitative MRI project


This repository contains the official MRI protocol, data and codes used for the **7T Spinal Cord Quantitative MRI (7T SC qMRI)** project, developed through a collaboration between **[CRMBM (Marseille, France)](https://crmbm.univ-amu.fr/topic/spinal-cord-imaging/)** and the **[Balgrist Spinal Cord Injury Centre (Zurich, Switzerland)](https://www.balgrist.ch/en/offer/centers/spinal-cord-injury-center/)**.  
The 7T-SC-qMRI project is motivated by **multi-center implementation** and is part of the **Traveling Human Spine (THS)** study across Magnetom, Terra, and TerraX systems. It supports reproducible, high-quality imaging of the cervical spinal cord at ultra-high field strength (7T).
